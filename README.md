GTA 6, posted on X from a public account, with make.fun's ghost in the picture
and a play code in the post's text.

- Entry post: https://x.com/8sxuas/status/2123755724283232725
- The meme: a bearded make.fun ghost who has waited 12 years for GTA 6,
  while its AI agent got paid on make.fun in the meantime.
- `main.ts` (Node 22, standard library only) reads `POST.json`, checks the
  post address is a well-formed X post URL, and prints the entry summary.
- `POST.json` names the entry post's address on X.
